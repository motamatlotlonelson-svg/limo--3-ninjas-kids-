# LIMO – Lesotho Instruction Machine for Organization

**Team:** 3 Ninjas Kids  
**Course:** CS3520  
**Milestone:** M1 – LIMO ISA

## Description
LIMO is a custom 32-bit load-store ISA inspired by RISC-V, designed with Sesotho mnemonics for educational purposes at the National University of Lesotho.

## Repository Structure
- `/docs` → Full ISA Specification (A1–A6)
- `/examples` → Sample LIMO assembly programs
- `/src` → Future simulator source code
- `/tests` → Future test cases

## Key Features
- 16 general-purpose registers
- Sesotho instruction mnemonics
- R, I, S, B instruction formats
- Support for arithmetic, logic, memory, and branch instructions

## Sample Programs
- `program1_arithmetic.limo` – Basic addition
- `program2_load_use.limo` – Demonstrates load-use hazard
- `program3_loop.limo` – Simple loop with branch
