    QUICK HELP

    Using the LIMO simulator

    1. Choose or type a LIMO program.
    2. Select Assemble program to validate and encode it.
    3. Use Step to advance one clock cycle; use Run and Pause for continuous execution.
    4. Inspect pipeline stages, datapath values, control signals, hazards and architectural state.
    5. Reset before trying a different program.

    The interface panels need to be connected to your team's JavaScript processor engine before they display live execution data.
